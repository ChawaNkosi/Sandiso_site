# Sandiso_site
Sandiso– Law Students' Council President Campaign Website

A responsive campaign website created for **Sandiso Mahlangu's** 2026 campaign for **Law Students' Council President** at the **University of Cape Town**.

## Live Preview

Once GitHub Pages is enabled, the site can be viewed at:

```
https://YOUR-USERNAME.github.io/REPOSITORY-NAME/
```

---

## Overview

This website serves as the official campaign platform, presenting:

- Candidate profile
- Campaign vision
- Election manifesto
- Student leadership experience
- Contact information

The design focuses on accessibility, responsiveness, and a modern campaign aesthetic while remaining lightweight and fast.

---

## Features

- Responsive design for desktop, tablet and mobile
- Sticky navigation
- Smooth scrolling
- Animated scroll reveals
- Expandable manifesto cards
- Modern typography using Google Fonts
- Pure HTML, CSS and JavaScript (no frameworks)

---

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts (Sora & Manrope)
